# Discord Quest Runner

Простой, легковесный и полностью безопасный инструмент для выполнения 15-минутных квестов в Discord (Discord Quests) без необходимости скачивать и устанавливать тяжелые игры.

## 🛡️ Безопасность и прозрачность
- **0 скачиваний сторонних бинарников**: программа копирует встроенный системный `cmd.exe` из Windows, который имеет официальную цифровую подпись Microsoft.
- **Никаких вирусов и токен-логгеров**: весь код написан на стандартной библиотеке Python (Tkinter) без скрытых модулей и сетевых запросов.
- **Чистое завершение**: процесс автоматически завершается по таймеру и не висит в памяти.

## 🎮 Поддерживаемые игры
- **Arknights: Endfield** (`endfield.exe`)
- **Where Winds Meet** (`wwm.exe`)
- **Пользовательская игра (.exe)** — возможность ввести любое имя исполняемого файла для будущих квестов.

## 🚀 Использование
1. Запустите `Start.bat` (или `main.py`).
2. Примите нужный квест в Discord (вкладка «Квесты» / «Инвентарь подарков»).
3. Выберите игру из списка и нажмите **«Запустить квест»**.
4. Discord определит активность игры. Подождите 16 минут до завершения таймера.
5. Заберите награду в Discord!

## 📋 Требования
- Windows 10 / 11
- Установленный Python 3 (используется встроенный модуль Tkinter)
